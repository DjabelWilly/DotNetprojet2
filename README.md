# DotNetprojet2
tests unitaires et debug 

## techno
ASP.NET Core

## Installation et Lancement de l'application

### Prérequis

.NET SDK
Visual Studio avec ASP.NET et développement web
Git

### Cloner le dépôt

Ouvrir un terminal ou Git Bash et exécuter :

git clone -b dev https://github.com/DjabelWilly/DotNetprojet2/tree/dev
cd DotNetprojet2

### Lancer l'application en local

Ouvrir le dossier du projet avec Visual Studio :

Fichier > Ouvrir > Projet/Solution > Sélectionnez le fichier .sln du projet.

Dans l’Explorateur de solutions, définir le projet de démarrage :

Clic droit sur le projet principal > Définir comme projet de démarrage.

S'assurer que le profil de lancement est bien configuré :

Vérifier que le profil (IIS Express) est sélectionné en haut de l’IDE.

Puis appuyer sur Démarrer (F5) pour lancer l’application.
