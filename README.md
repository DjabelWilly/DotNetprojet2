# DotNetprojet2
tests unitaires et debug 

## techno
ASP.NET Core

## Installation et Lancement de l'application

### Prérequis
Avant de commencer, assurez-vous d’avoir installé :

.NET SDK (version compatible avec le projet, ex. .NET 6 ou 7)

Visual Studio avec le workload ASP.NET et développement web

Git

### Cloner le dépôt

Ouvrez un terminal ou Git Bash et exécutez :

git clone -b dev https://github.com/DjabelWilly/DotNetprojet2/tree/dev
cd DotNetprojet2

### Lancer l'application en local

Ouvrez le dossier du projet avec Visual Studio :

Fichier > Ouvrir > Projet/Solution > Sélectionnez le fichier .sln du projet.

Dans l’Explorateur de solutions, définissez le projet de démarrage :

Clic droit sur le projet principal > Définir comme projet de démarrage.

Assurez-vous que le profil de lancement est bien configuré :

Vérifiez que le profil (IIS Express) est sélectionné en haut de l’IDE.

Cliquez sur Démarrer (F5) pour lancer l’application.
